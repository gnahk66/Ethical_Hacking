# Task 4.2D: Payload handling and Windows privilege context

[Back to portfolio](../README.md)

**Tools and concepts:** Metasploit, payload encoding, Windows tokens, UAC, RDP

**Source:** supplied SIT379 portfolio, physical PDF pages 69-79 (counting the first reflection page as page 1).

**Assessment snapshot:** Feedback Exceeded; final assessment not shown. This describes the uploaded portfolio, not a later or final grade.

## Objective
Investigate payload execution and distinguish an account name from its effective Windows privileges.

## Work documented
1. Identified missing connection and executable-format parameters in a provided payload-generation example.
2. Discussed sequential encoding and the difference between raw payload bytes and an executable wrapper.
3. Transferred the lab executable through a local web server. Endpoint real-time protection was disabled for the exercise.
4. Established a lab session and inspected identity and token privileges.
5. Recorded access to local credential material, then used a privilege-elevation helper and rechecked identity.
6. Observed a UAC-bypass attempt abort because the session was already elevated.
7. Investigated RDP configuration; the concluding evidence is mainly screenshots.

## Results and limits
The narrative reports SYSTEM access, but also describes privileged operations before that transition. This means a normal-looking username did not establish an unprivileged token. The exact starting integrity level and token configuration need better evidence.

The exercise does not establish antivirus evasion: protection was disabled. Encoder ranking describes properties within the tool and does not prove effectiveness against endpoint protection. Complete RDP connectivity is not independently established by the readable narrative.

## Defensive recommendations
Keep endpoint protection enabled, monitor suspicious execution and token impersonation, restrict administrator rights and remote access, and investigate unexpected credential-store access.

## Portfolio boundary
Executable payloads, credential dumps and repeatable credential-extraction instructions are not included. This repository records the learning and evidence limits of the original controlled exercise.
